# Ramin Osti Portfolio Website

A responsive, single-page personal portfolio built with HTML, CSS, and vanilla JavaScript. It can be hosted as a static website.

## Files
- `index.html` — all page content and semantic structure
- `styles.css` — responsive design system and visual styling
- `script.js` — mobile navigation, theme toggle, skill tabs, project concept modals, contact email draft, and scroll effects
- `ramin-osti-cv.pdf` — CV linked from the hero section

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

For a local development server, run this command from the project folder if Python is installed:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
Upload the three website files to a static host such as GitHub Pages, Netlify, or Vercel static hosting. No build step is required.

## Before publishing
- Add real project photographs or diagrams that you have permission to publish.
- The supplied CV PDF is linked from the hero section. Review the PDF before publishing to ensure it contains only information you want to share publicly.
- Review all wording and dates.
- The contact form uses `mailto:` and opens the visitor's email app. It does not store or transmit form data to a server.
- Proposed AI concepts are explicitly labelled as concepts, not completed or deployed systems.

## Privacy
The website excludes passport number, NIE, date of birth, and residential street address. It includes only the professional email, LinkedIn profile, and city-level location.
